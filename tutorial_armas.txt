1. INTRODUÇÃO
================================================================================

Bem-vindo ao tutorial de criação de armas do Reino Elemental! Este guia foi 
criado para ajudar editores iniciantes a criar suas próprias armas do zero.

O sistema de armas utiliza o arquivo "weapons.db" onde cada linha representa 
uma arma completa com todos os seus parâmetros.

IMPORTANTE: Sempre faça backup do arquivo weapons.db antes de fazer alterações!

ONDE ENCONTRAR:
- Servidor: /servidor/weapons.db (arquivo principal)
- O sistema carrega as armas automaticamente quando o servidor inicia

================================================================================
2. ESTRUTURA DO SISTEMA DE ARMAS
================================================================================

Cada arma no arquivo weapons.db segue esta estrutura:

```
nome=municao=som_tiro=sons_impacto=som_sacar=som_recarregar=dano=distancia=municao_no_carregador=municao_carregada=velocidade=velocidade_rajada=velocidade_recarga=requer_municao=permite_rajada=pode_ser_dropada=sons_impacto_corpo=som_descarregar=som_modo1=som_modo2=desconto_municao=som_tiro_distancia=degradacao
```

EXEMPLO REAL:
```
beretta_m9=9mm=beretta_m9_pistolfire1=rico,rico1,rico2=berettam9draw=berettam9reload=20000=100=15=0=400=400=3000=1=0=0=body1,body2,body3=berettam9empty=salarme=salarme=1=beretta_m9_pistolfire1=75
```

3. ANATOMIA DE UMA ARMA
================================================================================

Vamos quebrar cada parâmetro:

3.1 IDENTIFICAÇÃO:
- nome: Nome único da arma (sem espaços, use underscore)
- municao: Tipo de munição que usa

3.2 ÁUDIO:
- som_tiro: Som quando dispara
- sons_impacto: Sons quando atinge algo (separados por vírgula)
- som_sacar: Som ao equipar a arma
- som_recarregar: Som ao recarregar

3.3 COMBATE:
- dano: Dano que causa (valor numérico)
- distancia: Distância máxima do disparo
- municao_no_carregador: Capacidade do carregador
- municao_carregada: Munição já carregada (geralmente 0)

3.4 MECÂNICAS:
- velocidade: Tempo entre disparos (em milissegundos)
- velocidade_rajada: Velocidade em modo rajada
- velocidade_recarga: Tempo para recarregar

3.5 CONFIGURAÇÕES:
- requer_municao: 1=precisa munição, 0=munição infinita
- permite_rajada: 1=tem modo rajada, 0=só tiro único
- pode_ser_dropada: 1=pode ser dropada, 0=não pode

================================================================================
4. PARÂMETROS DETALHADOS
================================================================================

4.1 VALORES DE DANO RECOMENDADOS:
- Faca/Punho: 1000-5000
- Pistola: 15000-25000
- Rifle: 25000-45000
- Sniper: 40000-60000
- Metralhadora: 15000-30000
- Arma especial: 50000+

4.2 VALORES DE DISTÂNCIA:
- Corpo a corpo: 50
- Pistola: 75-100
- Rifle: 200-300
- Sniper: 300-500
- Metralhadora: 300-700

4.3 VELOCIDADES (em milissegundos):
- Pistola: 300-500ms
- Rifle semi-auto: 200-400ms
- Rifle automático: 100-200ms
- Sniper: 800-1500ms
- Metralhadora: 80-150ms

4.4 CAPACIDADE DO CARREGADOR:
- Pistola: 8-17 balas
- Rifle: 20-30 balas
- Sniper: 3-10 balas
- Metralhadora: 50-200 balas

================================================================================
5. TIPOS DE ARMAS
================================================================================

5.1 PISTOLAS:
- Munição: 9mm, .45ACP, .357
- Características: Baixo dano, média precisão, rápido manejo

5.2 RIFLES:
- Munição: 5.56mm, 7.62mm
- Características: Médio-alto dano, boa precisão, versáteis

5.3 SNIPERS:
- Munição: 7.62mm, .50cal
- Características: Alto dano, máxima precisão, lento manejo

5.4 METRALHADORAS:
- Munição: 7.62mm, .50cal
- Características: Alto dano, baixa precisão, alto volume de fogo

5.5 CORPO A CORPO:
- Munição: nada/none
- Características: Muito alto dano próximo, sem munição

5.6 ESPECIAIS/FUTURISTAS:
- Munição: cristal_de_luz, plasma, etc.
- Características: Efeitos únicos, alto dano, raras

================================================================================
6. SONS E EFEITOS
================================================================================

6.1 SONS DE TIRO COMUNS:
- armfire1, armfire2... armfire40: Sons de armas de fogo
- beretta_m9_pistolfire1: Som específico de pistola
- m24_sniper_rifle: Som de sniper
- cannon: Som de canhão

6.2 SONS DE IMPACTO:
- rico, rico1, rico2... rico12: Ricochetes
- body1, body2... body7: Impacto em corpo
- bazucahit: Explosão
- espadahit: Impacto de lâmina

6.3 SONS DE MANEJO:
- draw: Sacar arma genérico
- berettam9draw: Sacar pistola específica
- reload: Recarregar genérico
- empty: Arma vazia

6.4 SONS ESPECIAIS:
- rajadaativada/rajadadesativada: Mudança de modo
- silenciadorligado/silenciadordesligado: Silenciador

7. CRIANDO SUA PRIMEIRA PISTOLA
================================================================================

Vamos criar uma pistola simples chamada "pistola_iniciante":

PASSO 1: Definir as características básicas
- Nome: pistola_iniciante
- Munição: 9mm
- Dano: 18000 (moderado para pistola)
- Distância: 80 (típico de pistola)
- Carregador: 12 balas

PASSO 2: Escolher os sons
- Tiro: armfire27 (som de pistola)
- Impacto: rico1,rico2,rico3 (ricochetes)
- Sacar: armtomada1 (som de sacar)
- Recarregar: armarecarga3 (som de recarga)

PASSO 3: Definir velocidades
- Tiro: 350ms (velocidade média de pistola)
- Rajada: 350ms (mesmo que tiro único)
- Recarga: 2500ms (2.5 segundos)

PASSO 4: Configurações finais
- Requer munição: 1 (sim)
- Permite rajada: 0 (não, só tiro único)
- Pode ser dropada: 1 (sim)

RESULTADO FINAL:
```
pistola_iniciante=9mm=armfire27=rico1,rico2,rico3=armtomada1=armarecarga3=18000=80=12=0=350=350=2500=1=0=1=body1,body2,body3=armdescargada10=-old-menuchecked=-old-menuchecked=1=armfire27=70
```

8. CRIANDO UM RIFLE DE ASSALTO
================================================================================

Agora vamos criar um rifle automático chamado "rifle_combate":

CARACTERÍSTICAS:
- Nome: rifle_combate
- Munição: 5.56mm
- Dano: 32000 (alto para rifle)
- Distância: 250 (longo alcance)
- Carregador: 30 balas
- Modo rajada: SIM

SONS:
- Tiro: armfire14
- Impacto: rico,rico1,rico2,rico3,rico4
- Sacar: armtomada6
- Recarregar: armarecarga5

VELOCIDADES:
- Tiro único: 180ms
- Rajada: 120ms (mais rápido)
- Recarga: 3000ms (3 segundos)

RESULTADO:
```
rifle_combate=5.56mm=armfire14=rico,rico1,rico2,rico3,rico4=armtomada6=armarecarga5=32000=250=30=0=180=120=3000=1=1=1=body1,body2,body3,body4,body5=armdescargada7=rajadaativada=rajadadesativada=1=armfire14=200
```

9. CRIANDO ARMAS CORPO A CORPO
================================================================================

Armas corpo a corpo têm características especiais:

FACA SIMPLES:
```
faca_basica=none=meleeswordthtravel1=meleeswordohimpactleather1=armatomada3=-old-menuchecked=8000=50=0=0=400=0=0=0=0=0=espadahit=-old-menuchecked=-old-menuchecked=-old-menuchecked=0=-old-menuchecked=50
```

CARACTERÍSTICAS ESPECIAIS:
- Munição: "none" (sem munição)
- Distância: 50 (muito próximo)
- Carregador: 0 (não se aplica)
- Velocidade: 400ms (moderadamente rápido)
- Sons especiais de lâmina

ESPADA PODEROSA:
```
espada_heroica=none=espada=espadarico=espadadraw=espada_curta1=25000=50=0=0=300=0=1000=0=0=0=espadahit=espada_curta2=-old-menuchecked=-old-menuchecked=0=espada_curta2=50
```

================================================================================
11. BALANCEAMENTO E TESTES
================================================================================

11.1 DICAS DE BALANCEAMENTO:
- Armas de alto dano devem ser lentas
- Armas rápidas devem ter dano moderado
- Snipers: alto dano, baixa cadência
- Metralhadoras: dano médio, alta cadência

11.2 FÓRMULA DE EQUILÍBRIO:
DPS = (Dano ÷ Velocidade_em_segundos)
- Pistola: 40000-60000 DPS
- Rifle: 60000-100000 DPS
- Sniper: 30000-50000 DPS
- Metralhadora: 80000-120000 DPS

11.3 TESTANDO SUA ARMA:
1. Adicione a linha ao weapons.db
2. Reinicie o servidor
3. Teste no jogo com /give [nome_da_arma]
4. Ajuste os valores conforme necessário

DICAS FINAIS
================================================================================

1. **SEMPRE TESTE**: Teste cada arma no jogo antes de finalizar
2. **BALANCE PRIMEIRO**: Foque no equilíbrio antes dos efeitos especiais
3. **USE REFERÊNCIAS**: Examine armas existentes para aprender
4. **SEJA CRIATIVO**: Combine sons únicos para criar identidade
5. **DOCUMENTE**: Mantenha notas sobre suas criações

DEBUGGING:
- Se a arma não aparece: Verifique a sintaxe da linha
- Se não faz som: Verifique se os arquivos .ogg existem
- Se está muito forte/fraca: Ajuste o dano gradualmente
- Se trava o jogo: Verifique valores numéricos

ARQUIVOS IMPORTANTES:
- /servidor/weapons.db: Banco de dados das armas
- /cliente/includes/weapon.bgt: Sistema cliente
- /servidor/includes/weapons.bgt: Sistema servidor
