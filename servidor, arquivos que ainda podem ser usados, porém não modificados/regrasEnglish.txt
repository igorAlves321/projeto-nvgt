Game rules. (please read)
1. All players must respect and be respected regardless of sexuality, economic class, power within the game, etc. If a report is received of an insult about the aforementioned topics towards someone, they will be warned. if this continues, it will proceed to silence and / or ban it as the case may be.
2. Avoid spam in public chat. Repetitive messages sent in a very short amount of time will be considered spam. The person responsible for this will be warned only one time.
3. You can talk smoothly about any game, application, service, etc. We are not the best game nor do we seek to compete with an existing one. Each one has something that characterizes it. We are to have fun, not to compete.
4. It is forbidden to use programs that facilitate gameplay, such as the cheat engine. Person discovered using it will be banned indefinitely.
5. Any game bug (in a matter of maps, bots, etc) Feel free to report it by command /invocation so that it can be seen by the connected administrators. We will try to solve it as soon as possible.
6. It is allowed to create more than one account without going to the extreme of having many of them. If many characters that come from the same computer are detected, we will eliminate them.
Failure to comply with the rules set out above will be the cause of some punishment such as ban or silence. If you come only to cause disturbances in any chat channel, please avoid the annoyance of creating an account, and avoid us the annoyance of taking actions against you.
