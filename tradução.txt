# Documentação do Sistema de Tradução - Projeto Ig

## Introdução

Este documento descreve o sistema de tradução utilizado no Projeto Ig, um jogo de áudio desenvolvido em BGT (Blastbay Game Toolkit). O sistema permite a tradução completa da interface do jogo para diferentes idiomas, facilitando o acesso global ao jogo.

## Estrutura dos Arquivos de Tradução

### Localização dos Arquivos

Os arquivos de tradução estão localizados na pasta `cliente/lang/` e possuem a extensão `.lang`. Cada arquivo representa um idioma suportado pelo jogo:

- `portuguese.lang` - Português 
- `English.lang` - Inglês
- `spanish.lang` - Espanhol
- `french.lang` - Francês
- `Turco.lang` - Turco

### Formato dos Arquivos de Tradução

Os arquivos de tradução seguem um formato simples de "chave=valor":

- **Chave**: Identificador único usado no código para referenciar o texto
- **Valor**: Texto traduzido para o idioma correspondente

Exemplo de uma linha em um arquivo de tradução:
```
Menu principal. Escolha uma opção com as setas para cima ou para baixo, e pressione enter.=Menu principal. Escolha uma opção com as setas para cima ou para baixo, e pressione enter.
```

## Como o Sistema de Tradução Funciona

1. **Carregamento do Arquivo de Idioma**:
   - O sistema carrega o arquivo de idioma selecionado pelo usuário usando a classe `parsed_data` no arquivo `cliente/includes/parsed_data.bgt`
   - O método `set_arquivo()` lê o arquivo e separa as chaves e valores em arrays

2. **Obtenção de Textos Traduzidos**:
   - O método `get_value()` recebe uma chave e retorna o valor traduzido correspondente
   - Se a chave não for encontrada, o sistema retorna a própria chave como valor padrão

3. **Uso no Código**:
   - No código, as strings são referenciadas usando `pu.get_value("chave")` para obter o texto traduzido

4. **Seleção de Idioma**:
   - O usuário pode escolher o idioma através da função `select_language()` no menu de opções
   - O sistema salva a preferência de idioma e carrega o arquivo correspondente

## Processo para Tradutores

### Adicionando ou Atualizando Traduções

1. **Usando o Menu de Edição In-Game**:
   - Acesse o menu de edição de idiomas através da função `langs_menu()`
   - Navegue pelas linhas usando as setas direita/esquerda
   - Acesse os termos dentro de uma linha usando as setas cima/baixo
   - Pressione Enter no termo que deseja modificar
   - Use Ctrl+Espaço para salvar as alterações
   - Use Ctrl+P para visualizar uma prévia do termo a ser traduzido
   - Use Delete para remover um elemento
   - Use Ctrl+A para adicionar um novo elemento

2. **Editando os Arquivos Diretamente**:
   - Abra o arquivo .lang correspondente em um editor de texto com suporte a UTF-8
   - Mantenha o formato "chave=valor" em cada linha
   - Não modifique as chaves, apenas os valores após o sinal de igual
   - Salve o arquivo com codificação anci
