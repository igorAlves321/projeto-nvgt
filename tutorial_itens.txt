1. INTRODUÇÃO
================================================================================

Bem-vindo ao tutorial de criação de itens do Projeto Ig! Este guia foi 
criado para ajudar editores iniciantes a criar seus próprios itens do zero.

O sistema de itens utiliza o arquivo "items.db" onde cada linha representa 
um item completo com todos os seus efeitos e propriedades.

IMPORTANTE: Sempre faça backup do arquivo items.db antes de fazer alterações!

ONDE ENCONTRAR:
- Servidor: /servidor/items.db (arquivo principal)
- O sistema carrega os itens automaticamente quando o servidor inicia

================================================================================
2. ESTRUTURA DO SISTEMA DE ITENS
================================================================================

Cada item no arquivo items.db segue esta estrutura:

```
nome=itens_que_da=som_uso=mensagem=mapa_teleporte=nova_pos_x=nova_pos_y=xp=vida=sede=saciar_sede=fome=saciar_fome=degradacao
```

EXEMPLO REAL (Maçã):
```
manzana_roja=manzana_roja.-1=getapple=¡Te comes una deliciosa manzana roja!=none=0=0=0=0=-2=-2=-4=-4=0
```

EXEMPLO REAL (Pacote militar):
```
paquete_militar=paquete_militar.-1,beretta_m9.1,9mm.400=opensurvival_pack=none=none=0=0=0=0=0=0=0=0=0
```

3. ANATOMIA DE UM ITEM
================================================================================

Vamos quebrar cada parâmetro:

3.1 IDENTIFICAÇÃO:
- nome: Nome único do item (sem espaços, use underscore)
- itens_que_da: Itens que são dados quando usado (formato: item.quantidade)

3.2 FEEDBACK:
- som_uso: Som tocado quando o item é usado
- mensagem: Mensagem mostrada ao jogador
- mapa_teleporte: Mapa para onde teleporta (se aplicável)

3.3 POSICIONAMENTO:
- nova_pos_x: Coordenada X no mapa de destino
- nova_pos_y: Coordenada Y no mapa de destino

3.4 BENEFÍCIOS:
- xp: Experiência ganha
- vida: Vida curada

3.5 NECESSIDADES:
- sede: Alteração na sede (-valor = reduz sede)
- saciar_sede: Valor de sede preenchido
- fome: Alteração na fome (-valor = reduz fome)
- saciar_fome: Valor de fome preenchido

3.6 SISTEMA:
- degradacao: Taxa de degradação (0-100)

================================================================================
4. PARÂMETROS DETALHADOS
================================================================================

4.1 ITENS_QUE_DA:
Formato: nome_item.quantidade,outro_item.quantidade
- item.-1: Remove o próprio item após uso
- arma.1: Dá 1 unidade da arma
- municao.100: Dá 100 unidades de munição

Exemplos:
- banana.-1 (remove a banana após comer)
- pistola.1,9mm.50 (dá 1 pistola e 50 balas)
- poci­ón_vital.5 (dá 5 poções de vida)

4.2 SONS COMUNS:
- getapple: Som de comer fruta
- getbanana: Som de comer banana
- comer1-comer17: Vários sons de comer
- bebendoagua: Som de beber
- openpackage3: Som de abrir pacote
- opensurvival_pack: Som de abrir kit
- tomandomagia5: Som de tomar poção

4.3 VALORES DE VIDA:
- 1000-10000: Cura pequena
- 10000-100000: Cura média
- 100000-1000000: Cura grande
- 1000000+: Cura massiva

4.4 VALORES DE FOME/SEDE:
- Valores negativos (-1 a -100): Reduzem fome/sede
- Valores positivos (1 a 100): Aumentam fome/sede
- Valores de saciar (0-100): Quanto preenche a barra

================================================================================
5. TIPOS DE ITENS
================================================================================

5.1 ALIMENTOS (FRUTAS):
- Efeito: Reduzem fome e sede
- Som: getapple, getbanana
- Valores típicos: -2 a -40 fome/sede

5.2 BEBIDAS:
- Efeito: Reduzem principalmente sede
- Som: bebendoagua
- Valores típicos: -5 a -50 sede

5.3 POÇÕES DE CURA:
- Efeito: Restauram vida
- Som: tomandomagia5, b_antídoto
- Valores típicos: 30000-30000000000 vida

5.4 PACOTES/CONTÊINERES:
- Efeito: Dão múltiplos itens
- Som: openpackage3, opensurvival_pack
- Contém: Listas de itens

5.5 ITENS DE TELEPORTE:
- Efeito: Transportam para outro mapa
- Som: ma124, naveescudofall
- Requer: Coordenadas de destino

5.6 ITENS ESPECIAIS:
- Efeito: Múltiplos efeitos combinados
- Som: Únicos para cada item
- Podem dar XP, itens, cura, teleporte

7. CRIANDO SUA PRIMEIRA FRUTA
================================================================================

Vamos criar uma "laranja_doce":

PASSO 1: Definir características básicas
- Nome: laranja_doce
- Remove o item após uso: laranja_doce.-1
- Som: getapple (som de comer fruta)
- Mensagem: "Você come uma laranja doce e suculenta!"

PASSO 2: Definir efeitos
- Não teleporta: none, 0, 0
- Não dá XP: 0
- Não cura vida: 0
- Reduz sede: -15
- Preenche sede: -15
- Reduz fome: -8
- Preenche fome: -8
- Sem degradação: 0

RESULTADO FINAL:
```
laranja_doce=laranja_doce.-1=getapple=Você come uma laranja doce e suculenta!=none=0=0=0=0=-15=-15=-8=-8=0
```

9. CRIANDO PACOTES/CONTÊINERES
================================================================================

9.1 PACOTE DE SOBREVIVÊNCIA:
Vamos criar um "kit_iniciante" que dá arma, munição e comida:

```
kit_iniciante=kit_iniciante.-1,pistola_iniciante.1,9mm.100,manzana_roja.5,agua_pura.3=opensurvival_pack=Você abre o kit e encontra suprimentos essenciais!=none=0=0=0=0=0=0=0=0=0
```

CONTÉM:
- Remove o próprio kit: kit_iniciante.-1
- Dá 1 pistola: pistola_iniciante.1
- Dá 100 balas: 9mm.100
- Dá 5 maçãs: manzana_roja.5
- Dá 3 águas: agua_pura.3

9.2 CAIXA DE TESOURO:
```
caixa_tesouro=caixa_tesouro.-1,pocao_cura_maior.3,rifle_combate.1,5.56mm.150=openwoodbox=Você encontra tesouros valiosos na caixa!=none=0=0=1000=0=0=0=0=0=0
```

Inclui bônus de 1000 XP!

DICAS FINAIS
================================================================================

1. **SEMPRE TESTE**: Use /give para testar cada item criado
2. **BALANCE PRIMEIRO**: Efeitos poderosos devem ter custos/raridade
3. **USE REFERÊNCIAS**: Examine items.db existente para aprender
4. **SEJA CRIATIVO**: Combine efeitos para criar itens únicos
5. **DOCUMENTE**: Mantenha notas sobre suas criações

DEBUGGING COMUM:
- Item não aparece: Verifique sintaxe da linha
- Sem som: Verifique se arquivo .ogg existe
- Efeito errado: Verifique valores numéricos
- Crash: Verifique parâmetros obrigatórios

ARQUIVOS IMPORTANTES:
- /servidor/items.db: Banco de dados dos itens
- /servidor/includes/item_in_inv.bgt: Sistema servidor
