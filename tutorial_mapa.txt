1. INTRODUÇÃO
================================================================================

Bem-vindo ao tutorial de criação de mapas do Reino Elemental! Este guia foi 
criado para ajudar editores iniciantes a construir seus próprios mapas do zero.

O sistema de mapas do jogo utiliza arquivos .map com uma sintaxe específica 
que define pisos, paredes, sons, NPCs, teleportes e muito mais.

IMPORTANTE: Antes de começar, familiarize-se com o sistema de coordenadas:
- X: horizontal (0 = esquerda, valores maiores = direita)
- Y: vertical (0 = norte, valores maiores = sul)
- Z: altura (normalmente 0 para terreno)

================================================================================
2. ESTRUTURA BÁSICA DE UM MAPA
================================================================================

Todo mapa deve começar com estas linhas obrigatórias:

```
map:nome_do_mapa

maxx:300

maxy:200
```

EXPLICAÇÃO:
- map: Define o nome do mapa (use apenas letras, números e underscore)
- maxx: Largura máxima do mapa (coordenada X)
- maxy: Altura máxima do mapa (coordenada Y)

================================================================================
3. ELEMENTOS FUNDAMENTAIS
================================================================================

3.1 PISOS (PLATFORMS)
Sintaxe: p:x1:x2:y1:tipo_piso

Exemplos:
p:0:50:0:concrete      # Piso de concreto de x0 a x50, em y0
p:51:100:0:grass       # Piso de grama de x51 a x100, em y0
p:0:300:10:dirt7       # Piso de terra de x0 a x300, em y10

3.2 PAREDES (WALLS)
Sintaxe: w:x:y1:y2:tipo_parede

Exemplos:
w:0:0:200:camerawall    # Parede invisível na coordenada x0, de y0 a y200
w:300:0:200:camerawall  # Parede invisível na coordenada x300, de y0 a y200

3.3 DESCRIÇÕES DE ÁREA (ZONES)
Sintaxe: z:x1:x2:y1:y2:descrição

Exemplo:
z:1:50:0:20:Você está em uma pequena praça da cidade.

3.4 SONS AMBIENTES
Sintaxe: ss:x1:x2:y1:y2:arquivo_som.ogg

Exemplo:
ss:0:100:0:50:birds13.ogg    # Sons de pássaros na área especificada

4. CRIANDO SUA PRIMEIRA CIDADE SIMPLES
================================================================================

Vamos criar uma cidade pequena chamada "cidade_tutorial":

PASSO 1: Cabeçalho básico
```
map:cidade_tutorial

maxx:400

maxy:300
```

PASSO 2: Configurações iniciais
```
# Área indefinida (fora dos limites)
z:0:400:0:300:...

# Teto (skybox)
teto:none

# Dispositivos permitidos
dv:camera
dv:coordenadas
dv:bicicleta
dv:baculo
```

PASSO 3: Criando a praça central
```
# Piso da praça principal
p:50:200:50:concrete

# Descrição da praça
z:50:200:50:100:Praça central da cidade. Você pode ouvir o movimento das pessoas e o som distante do trânsito.

# Som ambiente da praça
ss:50:200:50:100:ambiente de autos.ogg
```

PASSO 4: Adicionando ruas
```
# Rua principal (norte-sul)
p:120:130:0:300:concrete5
z:120:130:0:300:Rua principal. Uma via movimentada que atravessa toda a cidade.

# Rua secundária (leste-oeste)
p:0:400:140:150:concrete5
z:0:400:140:150:Avenida comercial. Várias lojas podem ser vistas dos dois lados.

# Sons das ruas
ss:120:130:0:300:calle de una ciudad -  efecto de sonido.ogg
ss:0:400:140:150:ambiente de autos.ogg
```

PASSO 5: Criando um parque
```
# Área verde do parque
p:250:350:80:180:grass
z:250:350:80:180:Parque municipal. Um local tranquilo com árvores e bancos para descansar.

# Sons da natureza no parque
ss:250:350:80:180:birds7.ogg
```

================================================================================
5. TIPOS DE PISOS (PLATFORMS)
================================================================================

PISOS URBANOS:
- concrete: Concreto básico
- concrete3: Concreto rugoso
- concrete5: Concreto liso
- metal4: Plataforma metálica
- calcada: Calçada

PISOS NATURAIS:
- grass: Grama
- dirt7: Terra batida
- sand: Areia

PISOS ESPECIAIS:
- wood: Madeira
- stone: Pedra
- water: Água (apenas visual)

DICA: Os pisos afetam o som dos passos do jogador automaticamente!

================================================================================
6. SONS E AMBIENTAÇÃO
================================================================================

6.1 SONS AMBIENTES COMUNS:

NATUREZA:
- birds7.ogg, birds13.ogg: Pássaros
- floresta2.ogg: Floresta
- rain4.ogg: Chuva

URBANOS:
- ambiente de autos.ogg: Trânsito de carros
- calle de una ciudad -  efecto de sonido.ogg: Rua de cidade
- person.ogg: Pessoas conversando

INTERIORES:
- a1235.ogg: Ambiente fechado suave

6.2 SONS STEREO (ss2):
Para sons que tocam em todo o mapa:

```
ss2:0:400:0:300:2cancion.ogg:-0
```

6.3 SONS POSICIONAIS:
Para sons que vêm de pontos específicos:

```
ss:60:60:0:0:person.ogg    # Som de pessoa em coordenada específica
```

================================================================================
7. PAREDES E LIMITAÇÕES
================================================================================

7.1 PAREDES INVISÍVEIS (CAMERAWALL):
Usadas para delimitar o mapa:

```
w:0:0:300:camerawall      # Parede oeste
w:400:0:300:camerawall    # Parede leste
```

7.2 PORTAS (DOORS):
Sintaxe: dr:x:y1:x2:y2:altura:tipo:tipo2:som_abrir:som_fechar

```
dr:125:49:125:51:200:none:none:door17open.ogg:door17close.ogg
```

================================================================================
8. NPCs E DIÁLOGOS
================================================================================

8.1 CRIANDO UM NPC:
```
# Posição do NPC
z:60:60:0:15:Vendedor.

# Som quando próximo ao NPC
ss:60:60:0:0:person.ogg

# Diálogos do NPC
dlg:60:0:Olá! Bem-vindo à nossa cidade!:door17open.ogg
dlg:60:0:Posso ajudá-lo com alguma coisa?:door17open.ogg
```

8.2 NPCS COMPLEXOS:
```
z:80:80:0:15:Guarda da cidade.
ss:80:80:0:0:person.ogg
dlg:80:0:Esta é uma cidade pacífica.:door17open.ogg
dlg:80:0:Espero que aproveite sua visita.:door17open.ogg
dlg:80:0:Se precisar de ajuda, me procure.:door17open.ogg
```

================================================================================
9. TELEPORTES E CONEXÕES
================================================================================

9.1 TELEPORTE SIMPLES:
Sintaxe: tp:x1:x2:y1:y2:destino_x:destino_y:mapa_destino:mensagem

```
tp:390:400:140:150:10:10:centro_comercial:Você entra no centro comercial.
```

9.2 ZONA DE TELEPORTE COM DESCRIÇÃO:
```
z:390:400:140:150:Entrada do centro comercial.
tp:390:400:140:150:10:10:centro_comercial:Você entra no centro comercial.
```

================================================================================
10. DICAS AVANÇADAS
================================================================================

10.1 ORGANIZAÇÃO:
- Sempre comente seu código com # para seções importantes
- Agrupe elementos por tipo (pisos, então paredes, então NPCs)
- Use coordenadas organizadas (múltiplos de 10)

10.2 PERFORMANCE:
- Evite muitos sons sobrepostos na mesma área
- Use ss2 para sons de fundo gerais
- Limite o número de NPCs por área

10.3 ACESSIBILIDADE:
- Sempre inclua descrições detalhadas nas zonas
- Use sons apropriados para cada ambiente
- Teste o mapa caminhando por todas as áreas

11. EXEMPLO PRÁTICO COMPLETO
================================================================================

Aqui está um mapa completo de uma pequena cidade:

```
map:cidade_exemplo

maxx:300

maxy:200

# Área indefinida
z:0:300:0:200:...

# Configurações
teto:none
dv:camera
dv:coordenadas
dv:bicicleta
dv:baculo

# Paredes do mapa
w:0:0:200:camerawall
w:300:0:200:camerawall

# PRAÇA CENTRAL
p:100:200:80:120:concrete
z:100:200:80:120:Praça central da cidade. Um local movimentado com pessoas caminhando e conversando.
ss:100:200:80:120:ambiente de autos.ogg

# RUA PRINCIPAL
p:140:160:0:200:concrete5
z:140:160:0:200:Rua principal. Uma via que atravessa toda a cidade.
ss:140:160:0:200:calle de una ciudad -  efecto de sonido.ogg

# PARQUE
p:50:90:50:150:grass
z:50:90:50:150:Parque municipal. Um local tranquilo com árvores e o canto dos pássaros.
ss:50:90:50:150:birds7.ogg

# ÁREA COMERCIAL
p:210:290:60:140:concrete
z:210:290:60:140:Área comercial. Várias lojas e estabelecimentos podem ser encontrados aqui.
ss:210:290:60:140:person.ogg

# NPCs
z:150:150:0:15:Guia turístico.
ss:150:150:0:0:person.ogg
dlg:150:0:Bem-vindo à nossa cidade!:door17open.ogg
dlg:150:0:Esta é a praça central, coração da cidade.:door17open.ogg
dlg:150:0:O parque fica à oeste, e as lojas à leste.:door17open.ogg

z:70:70:0:15:Jardineiro.
ss:70:70:0:0:person.ogg
dlg:70:0:Cuidamos bem deste parque.:door17open.ogg
dlg:70:0:É um ótimo lugar para relaxar.:door17open.ogg

z:250:250:0:15:Comerciante.
ss:250:250:0:0:person.ogg
dlg:250:0:Temos as melhores lojas da região!:door17open.ogg
dlg:250:0:Não deixe de visitar nossa área comercial.:door17open.ogg

# SAÍDAS
z:149:149:190:200:Saída sul da cidade.
tp:148:152:195:200:150:10:estrada_sul:Você deixa a cidade pela estrada sul.

z:290:300:99:101:Saída leste da cidade.
tp:295:300:98:102:10:100:zona_rural:Você segue pela estrada que leva à zona rural.
```

DICAS FINAIS
================================================================================

1. TESTE SEMPRE: Coloque seu mapa na pasta servidor/maps/ e teste no jogo
2. USE REFERÊNCIAS: Examine mapas existentes para aprender técnicas
3. SEJA CRIATIVO: Use sons e descrições para criar atmosferas únicas
4. DOCUMENTE: Mantenha notas sobre o que cada área faz
5. ITERATE: Não tenha medo de modificar e melhorar seu mapa

SONS MAIS USADOS NO JOGO:
- door17open.ogg: Som padrão para interações
- person.ogg: Presença de pessoas
- birds7.ogg, birds13.ogg: Natureza
- ambiente de autos.ogg: Cidade/trânsito
- floresta2.ogg: Florestas
- calle de una ciudad -  efecto de sonido.ogg: Ruas urbanas

TIPOS DE PISO RECOMENDADOS:
- concrete: Uso geral urbano
- grass: Parques e áreas verdes
- dirt7: Estradas de terra
- concrete5: Ruas principais
- calcada: Calçadas e passarelas
