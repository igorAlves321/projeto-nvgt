Entendo que você está programando e precisa de ajuda para localizar as informações de rede. As classes e arquivos principais para implementação e teste de rede, e para conexões cliente-servidor no NVGT, são os seguintes:

*   **Classe `network` (Doc NVGT.txt)**: Esta é a classe central para todas as operações de rede. Ela permite que você:
    *   **Configure um cliente ou servidor**: Use `setup_client()` para se tornar um cliente ou `setup_server()` (ou `setup_local_server()`) para se tornar um servidor.
    *   **Conecte-se a um servidor**: O método `connect()` é usado para isso.
    *   **Envie e receba dados**: Métodos como `send()`, `send_reliable()` e `send_unreliable()` permitem enviar pacotes para outros peers. O método `request()` é fundamental para receber eventos de rede, como conexões, desconexões e pacotes recebidos.
    *   **Monitore o estado da rede**: A propriedade `active` indica se o objeto de rede está configurado. Você também pode verificar `bytes_received` e `bytes_sent`.
    *   **Eventos de Rede**: Os eventos de rede são retornados pela função `network::request()` e são do tipo `network_event`. Os tipos de evento incluem `event_connect`, `event_disconnect` e `event_receive`.

*   **Classe `http` (Doc NVGT.txt)**: Para requisições HTTP (comuns em comunicação cliente-servidor para serviços web), use esta classe. Ela oferece métodos para:
    *   Fazer requisições `GET`, `HEAD` ou `POST` de forma assíncrona.
    *   Acompanhar o progresso (`progress`), o código de status (`status_code`) e o corpo da resposta (`response_body`) da requisição.
    *   A função `wait()` pode ser usada para bloquear a execução até que a requisição seja concluída, ou você pode usar a propriedade `complete` em um loop para executá-la em segundo plano.

*   **Classe `internet_request` (Doc NVGT.txt)**: Embora a classe `http` seja mais simples para requisições HTTP, a `internet_request` também é mencionada para requisições de internet e possui propriedades para `bytes_downloaded`, `download_percent`, `upload_size`, `upload_percent` e `status_code`.

*   **Subsistema de Rede (Doc NVGT.txt, códigos.txt, nvgt_subsystems.nvgt)**: O NVGT possui um subsistema de rede identificado pelo valor `NVGT_SUBSYSTEM_NET = 0x40`. Isso indica uma camada de funcionalidade dedicada à rede.

Para **testar** essas funcionalidades, você usaria os métodos e propriedades dessas classes para:
*   Verificar o `status_code` de uma requisição HTTP.
*   Verificar se a conexão foi estabelecida com `network::active`.
*   Processar os `network_event` retornados por `network::request()` para lidar com conexões, desconexões e recebimento de pacotes.
